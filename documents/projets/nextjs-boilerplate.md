# Clément Ozor - Projet NextJS Boilerplate

NextJS Boilerplate est une base de départ réutilisable pour développer des applications web avec Next.js et TypeScript. Le projet regroupe une sélection d'outils pour l'interface, l'authentification, l'accès aux données, l'internationalisation et la validation des formulaires, afin de faciliter le démarrage de nouveaux projets.

Lien référencé dans le portfolio précédent : https://github.com/TheSn0wDev/nextjs-boiler-plate.

## Technologies et domaines référencés

TypeScript, Next.js, React, Tailwind CSS, Radix UI, NextAuth, Prisma, next-intl, React Hook Form, Zod.
