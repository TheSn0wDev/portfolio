# Clément Ozor - Projet Code Sandbox chez Thales

## Contexte

Clément Ozor a développé un environnement Code Sandbox durant son expérience de Software Engineer chez Thales à Vélizy, d'avril à juillet 2023.

## Objectif

Le Code Sandbox est un outil interne basé sur VS Code. Il embarque directement le SDK cartographique et une vue web pour afficher le rendu en direct. Les développeurs peuvent écrire du code directement dans cet environnement et observer son résultat.

Un SDK cartographique est un ensemble d'outils logiciels permettant d'intégrer des fonctions de cartographie à une application web.

## Usage pour le débogage

L'outil permet de reproduire et de déboguer des comportements du SDK en dehors des bases de code propres aux projets qui l'utilisent. Lorsque plusieurs projets ont des bases de code différentes, il aide à vérifier si un bug provient du SDK lui-même ou du code d'intégration d'un projet. La vue web permet d'observer le rendu en direct pendant cette investigation.
