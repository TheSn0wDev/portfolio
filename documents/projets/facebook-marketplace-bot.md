# Clément Ozor - Projet Facebook Marketplace Bot

## Présentation

Facebook Marketplace Bot est un bot Python qui automatise les réponses aux messages reçus à propos d'annonces Facebook Marketplace. Il détecte des questions courantes, comme la disponibilité d'un article, la livraison, son état ou l'adresse, puis envoie une réponse prédéfinie et configurable.

Le bot utilise la bibliothèque fbchat pour écouter les messages et y répondre. Son fonctionnement repose sur des règles et des mots-clés, sans modèle d'intelligence artificielle.

Le README présente ce projet comme la première utilisation de Python par son auteur.

Dépôt : https://github.com/TheSn0wDev/facebook-marketplace-bot.

## Technologies

Python et fbchat.
