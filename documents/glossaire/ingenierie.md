# Glossaire - Ingénierie logicielle et technologies web

## Backend, frontend et full-stack

Le backend exécute la logique côté serveur et gère notamment les données et les APIs. Le frontend est l'interface utilisée dans le navigateur. Le développement full-stack couvre les deux. Le parcours de Clément Ozor comprend ces trois domaines.

## API - Application Programming Interface

Une API est une interface qui permet à des logiciels de communiquer selon des règles définies. Une API web expose généralement des routes accessibles par des requêtes réseau. La route /api/health du portfolio v3 indique que le service répond.

## REST - Representational State Transfer

REST est un style d'architecture d'API fondé notamment sur des ressources, des interactions sans état de session côté serveur entre requêtes et une interface uniforme. Les APIs REST web utilisent couramment HTTP. Un endpoint HTTP ou un échange JSON ne suffit pas à prouver qu'une API suit REST.

## HTTP et WebSocket

HTTP est un protocole utilisé pour les échanges web, souvent selon un cycle requête-réponse. WebSocket permet une connexion persistante avec des échanges dans les deux sens, utile pour des messages ou événements en temps réel.

## SDK - Software Development Kit

Un SDK est un ensemble d'outils, de bibliothèques et de documentation pour intégrer ou développer sur une plateforme. Chez Thales en 2023, Clément Ozor a travaillé sur un environnement de test d'un SDK cartographique web.

## Code Sandbox

Une code sandbox, ou bac à sable de code, est un environnement permettant d'essayer du code et d'observer son comportement. Son niveau d'isolation dépend de sa conception.

Chez Thales à Vélizy, d'avril à juillet 2023, Clément Ozor a développé Code Sandbox, un outil interne basé sur VS Code. Il embarque le SDK cartographique et une vue web avec rendu en direct, permettant d'écrire du code dans l'outil et d'observer son résultat.

Code Sandbox sert notamment à reproduire et déboguer les comportements du SDK entre des projets dont les bases de code diffèrent. Il aide à déterminer si un bug provient du SDK lui-même ou du code d'intégration propre à un projet. Clément a également mis en place des tests de performance et des benchmarks du SDK.

Stack de cette expérience : TypeScript, React et Vitest.

## Systèmes distribués

Un système distribué répartit ses composants sur plusieurs processus ou machines qui communiquent par réseau. Son fonctionnement doit tenir compte notamment des délais, des pannes et de la cohérence des données. Le backend Thales de Clément Ozor comprend des composants d'intégration pour de tels systèmes.

## Architecture logicielle

L'architecture logicielle organise les composants d'un système, leurs responsabilités et leurs interactions. Elle aide à répondre aux exigences de fiabilité, d'évolution, de performance et de maintenance.

## Streaming vidéo, replay et multi-capteurs

Le streaming vidéo transmet un flux pour permettre sa lecture au fil de sa réception. Le replay permet de revoir un enregistrement. Un système multi-capteurs combine des informations provenant de plusieurs capteurs. Ces sujets figurent dans l'expérience robotique CoHoMa III de Clément Ozor.

## Tests, benchmark et Vitest

Un test vérifie un comportement attendu. Un benchmark mesure des performances dans des conditions définies. Vitest est un outil de test pour JavaScript et TypeScript. Clément Ozor l'a utilisé dans son expérience Thales sur le SDK cartographique.

## React et Next.js

React est une bibliothèque de construction d'interfaces à partir de composants. Next.js est un framework basé sur React qui fournit notamment le routage et des capacités côté serveur. La v3 du portfolio utilise Next.js avec React et TypeScript.

## Node.js et TypeScript

Node.js exécute JavaScript hors du navigateur, notamment côté serveur. TypeScript ajoute un système de types à JavaScript pour détecter certaines erreurs pendant le développement. Les types TypeScript ne remplacent pas la validation des données à l'exécution.

## Go, Python et Java

Go, Python et Java sont des langages de programmation généralistes. Go est utilisé dans les services backend Thales de Clément Ozor. Python apparaît dans ses travaux backend, robotiques et IA. Java figure dans la stack de son expérience backend chez Thales.

## C, C++ et Qt

C et C++ sont des langages utilisés notamment pour des logiciels proches du matériel ou soumis à des exigences de performance. Qt est un framework de développement d'applications, notamment d'interfaces en C++. C et C++ figurent dans l'expérience robotique ; Qt apparaît dans le portfolio précédent.

## HTML, CSS et JavaScript

HTML structure le contenu d'une page web. CSS définit sa présentation. JavaScript ajoute la logique et les interactions. Ces technologies sont associées notamment aux projets Ekalia et Skytale dans le portfolio précédent.

## WordPress et plugins

WordPress est un système de gestion de contenu pour créer et administrer des sites web. Un plugin ajoute des fonctionnalités, par exemple un formulaire ou une gestion des cookies. Clément Ozor a utilisé WordPress et configuré des plugins chez AZEOO.

## FastAPI

FastAPI est un framework Python de création d'APIs web. Il fournit notamment une description OpenAPI et des mécanismes de validation basés sur les types. FastAPI est cité dans Personal RAG ; la v3 actuelle du portfolio utilise les routes serveur Next.js.

## Lua

Lua est un langage de script intégrable dans d'autres applications, notamment utilisé dans certains environnements de jeux. Il apparaît dans les projets Atlantique RP, Next Citizens et pass-gen du portfolio précédent.

## Agile et Scrum

Agile désigne un ensemble de valeurs et principes favorisant notamment les retours réguliers et l'adaptation. Scrum est un cadre de travail avec des responsabilités, des événements et des cycles appelés sprints. Ces termes figurent dans les compétences de Clément Ozor.

## Lead Developer et cahier des charges technique

Un Lead Developer accompagne une équipe dans ses choix techniques et son développement ; le périmètre varie selon le projet. Un cahier des charges technique décrit les besoins, les contraintes et les attentes de réalisation. Sur Atlantique RP, Clément Ozor a aussi recruté des développeurs et managé cinq personnes.

## SaaS - Software as a Service

Un SaaS est un logiciel fourni comme un service accessible en ligne. Le fournisseur assure son exploitation. MMA Scan est décrit comme un SaaS de comparaison de combattants et d'analyse de combats MMA par IA.

## Atlantique RP

Atlantique RP était un serveur FiveM de jeu de rôle sur GTA V (GTA V RP). Son univers français se déroulait sur l'île d'Oléron. Il s'agissait d'un projet extra-professionnel de Clément Ozor, utilisant notamment Lua et React.

Clément Ozor y a été Lead Developer de janvier 2022 à septembre 2023. Il a recruté des développeurs, créé des cahiers des charges techniques et managé une équipe de cinq personnes.

Le projet Atlantique RP est aujourd'hui abandonné.
